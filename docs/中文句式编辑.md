# 中文固定句式编辑

人物卡仍以 JSON 保存，编辑时无需编写 JSON。资源表单及流程参数使用中文标签，复杂内容由确定句式编译为内部数据。旧版人物卡可直接打开，原有标识、引用与公式接口保持兼容。

可使用“表单”填写，或在“中文句式”页修改完整声明。点击“从表单生成句式”可以查看当前填写内容对应的语句；保存采用当前页面的内容。新建时会自动填入可修改的句式范本。

固定句式示例（每层四个空格）：

```text
记录：
    设置 默认值：
        数值：0
    设置 最大值：
        数值：3
    设置 可叠加：
        是
```

列表：

```text
列表：
    添加：
        文字：精神影响
    添加：
        文字：负面效果
```

“是”“否”是开关；“数值：”后填写数字；“文字：”后填写文字；“选项：”后保留已有中文选项。空记录写“记录：”，空列表写“列表：”。程序对缩进、重复名称、数值和资源结构进行检查；不执行任意代码。文字换行写 `\n`，反斜线写 `\\`。自定义字段名称前的“原名·”用于精确保留名字，编辑时保留该前缀。

输入、输出和默认设置均有完整范本。内部标识由程序自动生成，一般无需修改；它仍用于可靠关联资源。计算节点的计算式继续使用受限的算术表达式，尚非自由自然语言。旧 NDSL 文件和 JSON 文件的读取功能保留。
